# AI Scaler Toolkit Wiki

Knowledge base for **AI Scaler Toolkit (AST)**: how the service works inside, how to choose an
inference engine, how memory offload to DRAM and SSD works, fine-tuning, the API's behaviour, and
measured results.

AI Scaler Toolkit 的知識庫：服務內部怎麼運作、怎麼選推論引擎、記憶體怎麼 offload 到 DRAM 與
SSD、微調、API 的行為細節，以及實測結果。
