Startup

Start automatically with Windows
Runs in the background from the moment you sign in. The service needs a minute or two to load the GPU runtime, so this is the difference between opening the window and waiting, and opening the window and using it.

Ports

Application port
The API and this application's interface are both served here. Changing it restarts the service and repoints the interface at the same time.
Let other computers on this network use it
Off, the service answers only this computer. On, any computer on the same network can use it — there is no password, so anyone who can reach it can use the model you have loaded, and load or unload others. Turn it on for a network you trust.

    Environment

      Reinstall the environment
      Removes the Python environment and GPU runtime and installs them again — about ten minutes. Use this if the application starts but the backend will not. Your downloaded models are kept.
